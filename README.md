# Chronicles of the Elemental Guardian ⚔️🔥💧

## Overview

**Chronicles of the Elemental Guardian** is a 2D action RPG developed in Unity as part of my **Concurrent Design** university project. The game combines fast-paced combat, elemental abilities, enemy encounters and exploration across multiple levels.

The project was developed collaboratively using an iterative, sprint-based workflow, with the team responsible for designing, implementing and refining a functional game prototype.

## Gameplay

Players control an elemental guardian who can explore the environment, fight enemies and use different elemental abilities during combat.

### Key Features

* ⚔️ **Real-time combat** with melee attacks and ranged abilities
* 🔥 **Elemental abilities** including Fire, Water and Air
* 🛡️ **Defensive mechanics** including blocking and damage mitigation
* ❤️ **Health and mana systems** with regeneration
* 🧪 **Potion pickups** that affect player statistics
* 👾 **Multiple enemy types** with different stats and behaviours
* 🤖 **Enemy detection and AI movement**
* 💥 **Projectile-based combat**
* 🎯 **Cooldown and ability management**
* 📊 **Player and enemy health interfaces**
* 🗺️ **Multiple playable levels**
* 🎬 **Main menu, death and success screens**
* ✨ **Combat effects, animations and UI feedback**

## Technical Implementation

The game was developed using **Unity and C#**, with a focus on object-oriented programming and separation of responsibilities.

The codebase is organised into several layers:

* **Controller** – manages player, enemy, camera and gameplay interactions
* **Model** – contains player statistics, combat systems, skills, enemies, projectiles and object pooling
* **View** – manages UI elements, health bars, menus and gameplay feedback

The project also uses **object pooling** for frequently spawned gameplay objects such as projectiles and combat effects, helping reduce unnecessary runtime object creation.

The player combat system uses a reusable skill architecture, allowing different elemental abilities to inherit from a common `Skill` class while implementing their own damage type, projectile and mana cost.
